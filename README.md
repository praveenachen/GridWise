# Growth Readiness Dashboard (MVP)

Prototype for a City of Ottawa decision-support dashboard to assess where growth is likely,
how ready areas are, what the main constraints are, and recommended actions to unlock housing.

This repo is intentionally lightweight and built for a fast, explainable demo.

## Project Structure
- `frontend/` UI (map + readiness panels)
- `backend/` simple rule engine (optional; can be skipped for static demo)
- `data/` sample areas and mock evidence
- `configs/` scoring rules and weights
- `docs/` implementation plan and notes

## Quick Start
```powershell
cd frontend
npm run dev
```
